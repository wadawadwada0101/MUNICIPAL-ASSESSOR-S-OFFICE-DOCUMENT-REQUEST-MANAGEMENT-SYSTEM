# MUNICIPAL-ASSESSOR-S-OFFICE-DOCUMENT-REQUEST-MANAGEMENT-SYSTEM
This is a console-based Python application designed to help local barangay or government offices manage document requests and appointments right from the terminal. It provides a simple, text-based menu that allows residents to view document requirements, check their application status, and book appointment slots without needing a complex web interface.
# FEATURES
# Main Menu
*  Residences - Create Account and login
*  Staff - Login required
*  Exit program 
# Residence menu
  1. Submit Document Request
  2. My Requests and Appointments
  3. View Available Documents
  4. Book an Appointment
  5. Cancel Appointment
  6. Log Out
# Staff menu
  1. Request Monitoring
  2. Verify Requirements
  3. Resume Request Review
  4. Update Request Status(Under Review,Action Required,Ready for Release,and Released.)
  5. Logout
